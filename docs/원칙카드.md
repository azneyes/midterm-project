# 원칙 카드 (5칸) [권장]

> 고친 원칙마다 한 장. 다섯 칸을 모두 채우면 기획 · 코드 · 영상 · 셀프 논증 기록이 같은 번호로 이어집니다.
> P번호 = 닐슨 원칙 번호. 발표 자료 부록(원칙 카드 전부)에 그대로 옮깁니다.
> '판단' 칸은 셀프 논증 기록의 "내 주장 → 반론 → 재반론 → 결론 → 근거"를 줄여 쓴 것입니다.
> '근거' 칸의 리뷰는 `docs/리뷰분석.md`(Google Play, 2026-10-29 확인, 작성자 이름 지움)의 번호(R1–R17)로 찾을 수 있습니다.
